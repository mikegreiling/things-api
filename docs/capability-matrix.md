# Capability matrix — CRUD across write surfaces

**This is a LIVING DOCUMENT and the project's feature wish-list.** Update it in the same change as: any operation-catalog edit (`src/write/operations.ts`), any vector-matrix edit, any new probe verdict, or any gap opened/closed. Its sibling [things-app-oddities.md](things-app-oddities.md) (the future Cultured Code report) has the same contract: record every newly discovered app bug/quirk when it's found, not later. Both reminders also live in the repo `CLAUDE.md`.

Every **read** is complete and vector-independent (direct SQLite): views, detail, tags/areas/projects, search, changes, repeat-rule decoding, occurrence projections. The one read caveat: **sidebar order** (areas, top-level projects) is provisional — AppleScript enumeration does not match the sidebar (P19), so `index`-based reads are best-effort. This matrix therefore tracks **writes**.

Legend: ✅ shipped & lab-validated · 🟢 **shipped via the ui vector — lab-certified, on-device pending**[^ui] · 🟡 works with caveats · 🧪 plausible but unprobed (**wish list**) · 🚫 validated dead end (revisit per Things release) · ⛔ the app has no such concept · ➖ not applicable. Probe ids cite [docs/lab/](lab/harness.md) evidence; the authoritative op×vector data is `things capabilities`.

**Field ceilings cut across every row (NOTECAP1, 2026-08-27, Things 3.23).** Things stores an over-long field value as a silent truncated PREFIX — no error, the row still created or mutated — so the write layer refuses over-long values before dispatch at the parameter registry. The measured caps: **notes** min(10,000 grapheme clusters, 40,000 UTF-16 code units), and that one is the URL scheme's alone (AppleScript `set notes` stores 60 KB); **every title/name** (to-do, project, heading, checklist item, area, tag) 4,000 UTF-16 code units, identical on every vector because it is the app's own model; **checklist items** 100 per dispatch on `add`, `update` and `things:///json` alike. No URL-length ceiling exists below 1,000,100 characters, so no cell's vector choice is affected. Full matrix: [lab/notecap1-notes-ceiling.md](lab/notecap1-notes-ceiling.md); oddities §2j.

Gaps any future op must clear, all named rather than assumed: (a) the date is typed into a **natural-language search field**, so the recipe must type → read the resolved row back → commit (blind emission is unsafe: `next thursday` at a Sunday clock resolves to the *following* Thursday); (b) the branch set is **not fixed** — a calendar-date target offers three buttons, a bucket target (`Today`, `Someday`) offers two and slides `Cancel` to `action-button-2`, so buttons must be addressed by TITLE; (c) it is **irreversible headlessly** — the app's own ⌘Z is a perfect inverse (row hard-deleted, cursor rewound) but we can neither hard-delete one row (§5i) nor write the cursor backwards, so an uncomplete/trash leaves residue AND a permanently skipped slot; (d) DIALOG-class SESSGATE gating applies (a sheet on the main window); (e) unmeasured on repeating PROJECTS and across sync. **REPX3 (2026-08-23, golden-v4 / 3.23) closes the non-daily cell and opens a HAZARD.** On a rule where the two cursor columns differ, `Make Exception` sends `rt1_nextInstanceStartDate` to the **next RULE date** and `rt1_instanceCreationStartDate` to the **consumed slot + 1** — never to the chosen day + 1 — which is byte-for-byte the bookkeeping an ordinary clock spawn writes for that slot (measured on weekly and every-2-days arms against Cancel controls); the series then resumes its ordinary cadence at the next rule date. ## Acknowledged absences — real gaps with no register entry anywhere else

Genuine limits, recorded here so they are not mistaken for oversights:

- **File / image attachments** — Things stores note attachments, but no write vector exposes them and no probe has ever targeted them. There is no add/read/remove-attachment capability, by omission rather than by decision.
- **Full-database export / backup-restore** — `things batch` (JSONL through the pipeline) and `things changes --since` (incremental delta scan) exist, but there is **no whole-library snapshot, export, or restore story**. Backup is the app's / iCloud's concern; we offer no dump-and-reload path and make no durability promise.
- **English-locale-only doctrine (ui vector)** — every ui-vector recipe pins **English element titles** and refuses fail-closed under a non-English app locale ([design/ui-vector.md](design/ui-vector.md) "Localization pinning"). The GUI-driven ops are unavailable on a localized Things install until AXIdentifier-based addressing replaces the title-pinned steps.
- **No watch / subscribe mode (yet)** — there is no push, long-poll, or event-stream surface today; `things changes --since <timestamp>` is the pull-based substitute (a consumer polls for what changed since it last looked). A live change-watch mode is a queued feature-design item ([up-next.md](up-next.md) `things watch`), not a permanent absence.
- **`todo clone` / `project clone` — SHIPPED (mg/clone-ops).** First-class clone ops land as an orchestrated compound over official write surfaces (`src/write/clone.ts`), per the CLONE verdict-A fidelity matrix ([lab/clone-fidelity-and-template-trash.md](lab/clone-fidelity-and-template-trash.md), golden-v2/3.22.12): title/notes/tags/`when`/reminder/deadline reproduce in the base add; checked checklist items via a follow-up leg (A2); logged/canceled state (item AND project children) via `complete`/`cancel`+`set-dates` legs at the exact stopDate (A5/A7); projects rebuild area + headings + headed/root children in one `things:///json` import (A4). Refusals: trashed source, repeating template, and a project subtree holding a live nested repeating template (A6, named). `--title` / `--preserve-created` (minute res, disclosed); undo trashes the minted clone (+ children). The **promote-via-clone** rewiring (`clone → trash → native-promote`) + the `todo.add-repeating` / full-vocab `project.add-repeating` composites SHIPPED in phase 3 (2026-08-13, `src/write/promote-clone.ts`) — make/add-repeating are now recoverable + `things undo`-reversible; VM lab certification COMPLETE (UIC8, 2026-08-13, golden-v2/3.22.12 — [lab/uic8-promote-clone-cert.md](lab/uic8-promote-clone-cert.md)); the two findings from that run (reminder-bearing promote; `--preserve-modified` threading) were FIXED and re-certified in PR mg/uic8-fixes (RE-CERT addendum). Residuals: child checklist checked-state and child reminders are born plain (not reproduced).
