**Tag references (any op that accepts tags — `todo.add`, `todo.set-tags`, `project.set-tags`, `area.add`, `area.update`):** a tag value is a **title** or a **path-qualified `parent/child`** name (literal-over-path precedence per TAGW1-d) — **names only; tag uuids are an internal detail, never accepted or surfaced.** The resolver is a pure EXISTENCE check: a name matching ≥1 tag passes the name through (the app resolves it, as its GUI does — duplicate names need no disambiguation); a name matching none is unknown. Unknown tags stay fail-closed via `H-UNKNOWN-TAG`; pass **`--create-tags`** (CLI) / `createTags` (MCP) to create the missing ones first through the CLEAN `make new tag` path (mkdir-p intermediates for a path; idempotent via the TAGW1-c coalesce) and then apply.
